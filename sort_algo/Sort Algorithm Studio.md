Create "Sort Algorithm Studio" Application with Qt kit 6.12 with latest MinGW C++ in D:\exercise\sort_algo.
This project aims to provide the similar facilities from Graph Algorithm Studio", educating and researching.

1. This app shall contain
	1.1 C++ Modules to implement related data structures and sort algorithms, which will be built in Visual Studio 2026 (MSVC supports C++20 module and concept)
	    These implementation must fully support C++ module and concept for generic programming.
		in phase 1, implement simple sort algorithms - Bubble, Selection, Insertion, Cocktail, and Cycle.
	1.2 These modules will be imported to header files to Qt.
	1.3 Qt Modules: Home, Sort Algorithm Analyzer, Sort Algorithm Visulizer, and Sort Knowledge
	1.4 Home shall contain a startup screen, and contain three cards for analyzer, visualizer, and knowledge.
	1.5 User can use these cards to get into specific Qt Modules.
	
2. This app uses Qt QML, JavaScript, C++, and other related technologies.

3. Use sa_logo.svg as app icon.

4. Use "Graph Algorithm Studio" as a reference.
