Create "Search Algorithm Studio" Application with Qt kit 6.12 with latest MinGW C++ in D:\exercise\search_algo.
This project aims to provide the similar facilities from "Sort Algorithm Studio" and "Graph Algorithm Studio", educating and researching.

1. This app shall contain
	1.1 C++ Modules to implement related data structures and search algorithms, which will be built in Visual Studio 2026 (MSVC supports C++20 module and concept)
	    These implementation must fully support C++ module and concept for generic programming.
		in phase 1, implement the core search algorithms grouped by category:
		  - Sequential (no ordering needed): Linear, Sentinel.
		  - Sorted (require a sorted array): Binary, Ternary, Jump, Exponential, Interpolation, Fibonacci.
	1.2 These modules will be imported to header files to Qt.
	1.3 Qt Modules: Home, Search Algorithm Analyzer, Search Algorithm Visualizer, and Search Knowledge
	1.4 Home shall contain a startup screen, and contain three cards for analyzer, visualizer, and knowledge.
	1.5 User can use these cards to get into specific Qt Modules.

2. This app uses Qt QML, JavaScript, C++, and other related technologies.

3. Use search_logo.svg as app icon.

4. Use "Sort Algorithm Studio" as a reference.
