Create an umbrella, named as Algorithms, under Algorithms folder.

The rationales to create such an application are
1. users have a single application to work with a group of algorithm studios.
2. developers have a repo to maintain.
3. new app should combine repeated several build processes into one: converting cpp ixx files to headers, and creating installers.
4. use consistent scripts to do similar tasks, such as clean build artifacts.

The "Algorithms" has a home page containing cards to navigate into indivisual algorithm studios, currently Search, Sort, and Graph, also create other cards, Foundation, Combinatorials, and Numericals.
on the titlebar, add theme options.
